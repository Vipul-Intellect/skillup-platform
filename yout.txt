==================================================
FINAL RECOMMENDATION DESIGN
==================================================

The goal is to improve the current YouTube recommendation system from basic curated/popularity-based selection into a topic- and learner-aware educational recommendation system.

The final recommendation factors are:

1. TOPIC / SKILL MATCH
   - Very high importance.
   - The video must be relevant to the currently selected Skill/topic.

2. CONCEPT COVERAGE
   - Very high importance.
   - Prefer videos that cover the concepts relevant to the selected topic.

3. LEARNER-LEVEL FIT
   - High importance.
   - The recommendation should fit the learner's current validated level already available in SkillUp.

4. LEARNING OBJECTIVE MATCH
   - Conditional/optional.
   - Use only when a meaningful learning objective is already available from the existing flow.
   - Do NOT add a new mandatory objective input merely for this feature.

5. CONTENT FOCUS / SCOPE
   - Medium-high importance.
   - Prefer focused educational content rather than videos that are too broad, unrelated, or overly shallow for the selected topic.
   - Existing preferred-duration information can contribute to this fit.
   - Do not create a second duration system.

6. SOURCE / EDUCATIONAL QUALITY
   - Medium importance.
   - Trusted/educational sources can receive a positive signal.
   - IMPORTANT: trusted channels are NOT a hard whitelist.
   - Do not restrict recommendations to a static channel list.

7. TECHNICAL FRESHNESS / VALIDITY
   - Medium importance.
   - Prefer technically current and valid content where metadata/content evidence supports that conclusion.
   - Do not pretend that metadata can prove technical correctness when it cannot.

8. ENGAGEMENT
   - Low importance.
   - Views/likes may be supporting evidence only.
   - They must not override topic relevance, concept coverage, or learner-level fit.
